# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- The author, a data scientist, who runs the pipeline on a new tabular file and reads the report to understand the data before modelling: what is missing, how each column behaves, what relates to the target, and what to do before training.
- People who see the project in a portfolio (recruiters, other data scientists), who open a published sample report and judge in seconds whether the tool is serious and well made.

## Product Purpose

One command turns any tabular file (CSV, TSV, Excel, Parquet, JSON) into a self-contained HTML report: data quality, statistics, outliers, relationships, multicollinearity, target analysis, 40+ charts and a preprocessing plan in which every recommendation carries the measurement that produced it. Success is a report a person can scan to find what needs attention, and trust because every claim shows its evidence.

## Positioning

Every recommendation is measured, not asserted: each line of the plan states the number behind it, and the rules that produce it were measured across real datasets before they were adopted.

## Operating Context

- The report is opened from disk (`reports/<dataset>_<timestamp>/report.html`) in any browser, often offline, and sometimes printed.
- It is read top to bottom the first time and then used for reference: jumping to a section, checking a column, copying the column lists.
- A published copy of a real report (Kaggle's Spaceship Titanic) serves as the portfolio demo.

## Capabilities and Constraints

- The report is one HTML file that works without internet: no CDN, no external fonts, images embedded. System fonts only.
- The report is in English.
- Content, figures, section texts and the anchors the tests rely on (`id="target"`, `id="transformaciones"`…) are product truth; a redesign changes layout and presentation, not what the report says.
- Charts are matplotlib PNGs generated by the pipeline.
- Light and dark themes, following the system, with a toggle.
- Interactivity stays minimal and inline: active section in the navigation, collapsible blocks, theme toggle, back to top.

## Evidence on Hand

- Real reports for the datasets in `data/raw` (Spaceship Titanic, Kaggle Titanic, Housing Prices, Steam, Vistara, penguins and others), regenerated with `eda analyze-file` / `analyze-batch`.
- `docs/report-preview.png` and the README screenshots.

## Product Principles

- Evidence beside every claim: a reader can check a number instead of believing it.
- What needs attention is visible first; detail follows.
- A working tool first, and polished enough to show.
- Nothing hidden that a reader needs: collapsing is for length, never for content.

## Accessibility & Inclusion

WCAG 2.2 AA as the floor: contrast, full keyboard use with visible focus, reduced motion respected, useful alternative text on every chart.
